# 4周年記念 お便り大賞 — 投稿データ反映版

- 受領した「投稿まとめ.7z」内の46個のZIPに含まれるCSVから、**全384件（原資料）**を読み込みました（2022年12月〜2026年10月）。
- ユーザーの指定どおり、投稿者名の記入がない場合は「リスナー」。古いフォームで質問者名の列自体がない場合も同様です。
- 「自由欄」の内容は質問本文の末尾に改行を入れて `PS:内容` と表示します（133件）。原文の改行を維持します。
- 同文の投稿を含む全件を収録しました。同文だからという理由で勝手に削除していません。
- 過去のGoogleフォームの投稿日を `date` に使用しています。放送の実施月と必ずしも一致しません。
- Googleフォームの設定には会話で提供されたURLと3つのentry IDを登録済みです。
- **今回の納品物は選定済み66件入りです。** 100件に絞って公開する場合は、候補を確認して `letters.json` から対象外のデータを除いてください。番号変更後は投票番号も変わるため、公開前に確定させること。
- `letters.json` には、本文・自由欄・投稿者名・カテゴリ・元ファイル名・投稿日を保持しています。公開時はこれらの情報もWebから取得できるため、必ず公開前に内容を点検してください。

## 動作確認

1. このフォルダ内で `python -m http.server 8000` を実行。
2. `http://localhost:8000/` にアクセス（HTMLを直接開くとJSONが読み込めないことがあります）。
3. 一覧上の名前、PS、選択とフォームへの事前入力を確認してください。
4. `index.html`、`style.css`、`app.js`、`config.js`、`letters.json` をGitHub Pagesのリポジトリに登録して公開します。

## 注意

- 個人情報、投稿者名、著作物などの公開可否は必ず運営者が確認してください。
- Googleフォームへの事前入力は送信ではありません。投票者が「送信」します。
- ログイン不要の投票では厳密な多重投票防止はできません。

## 今回の修正

## カード表示の修正（今回）

- PCでは2列グリッドのまま、左右のカードの高さを行単位で揃えます。スマホでは1列にします。
- 本文表示の上限を広げました。短文は省略せず全て表示します。
- 実際に本文が省略されるカードにだけ「全文を見る」を出します。画面幅変更時にも判定します。
- 差し替えは `style.css` と `app.js` の2ファイル。
